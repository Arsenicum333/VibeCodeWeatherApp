# Agent instructions

This is a workshop demo app that shows how to build map applications with OpenLayers in Angular.

## No tests

This repository intentionally has no tests. Do not create test files (`*.spec.ts`, `*.test.ts`, e2e tests), install testing packages, or add test scripts or configuration. To check a change, run `npm run build` and look at the app with `npm start`.

The full rules are in [.agents/skills/no-tests/SKILL.md](.agents/skills/no-tests/SKILL.md). A copy for Claude Code is in `.claude/skills/no-tests/SKILL.md`; keep both files identical.
